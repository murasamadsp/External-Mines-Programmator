# 📚 External Mines Programmator - Документация

Добро пожаловать в систему документации проекта **External Mines Programmator** (EMP).

## 🎯 Назначение

Эта документация служит **системой спецификаций** для разработки новых функций. Вы описываете требования в промптах, а AI реализует их на основе этой документации.

## 🚀 Как использовать

### Для добавления новой функции:

1. **Опишите требование** в промпте
2. **Укажите ссылки** на существующие спецификации
3. **AI реализует** функцию на основе документации

### Пример промпта:

```
Добавь функцию [НАЗВАНИЕ] со следующими характеристиками:
- Тип: [UI/CORE/SERVICE]
- Параметры: [ОПИСАНИЕ]
- Поведение: [ОПИСАНИЕ]
- Интеграция: [с какими компонентами]

Смотри спецификации в: docs/features/[ФАЙЛ].md
```

## 📋 Ключевые компоненты

### 🎮 Programmator Core
- **ProgAction enum**: 255 действий бота
- **Program модель**: управление инструкциями
- **Serializer**: кодирование/декодирование программ
- **LZMA компрессия**: эффективное сжатие

### 🎨 User Interface
- **Grid система**: 16x12 ячеек с пагинацией
- **Action Palette**: категоризированная палитра команд
- **Controls**: импорт/экспорт, валидация
- **Responsive дизайн**: адаптивный интерфейс

### 🔧 Services
- **LZMA compression**: WebAssembly + JavaScript fallback
- **Storage**: локальное сохранение программ
- **Validation**: проверка корректности программ

## 🎯 Спецификации функций

### Текущие функции:
- ✅ **Базовый программатор**: сетка 16x12, 16 страниц
- ✅ **Палитра действий**: 255 команд, категоризированные
- ✅ **Экспорт/импорт**: Base64, Text, Codes форматы
- ✅ **Валидация**: проверка программ
- ✅ **LZMA компрессия**: эффективное сжатие

### Планируемые функции:
- 🔄 **Сниппеты**: шаблоны программ
- 🔄 **Отладчик**: пошаговое выполнение
- 🔄 **Макросы**: повторяющиеся последовательности
- 🔄 **Импорт из игры**: синхронизация с Mines

## 📝 Как добавить новую функцию

1. **Создайте спецификацию** в `docs/specs/` или `docs/features/`
2. **Опишите API** в `docs/api/`
3. **Добавьте в архитектуру** в `docs/architecture/`
4. **Создайте промпт** для реализации
