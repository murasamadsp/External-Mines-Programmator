# 📋 Спецификация ProgAction Enum

## 🎯 Обзор

`ProgAction` - это перечисление всех возможных действий, которые может выполнять бот в игре Mines. Каждое действие имеет уникальный числовой код от 0 до 254.

## 🔧 Структура enum

```javascript
const ProgAction = {
  // Базовые действия (0-9)
  None: 0,
  Forward: 1,
  Right: 2,
  Left: 3,
  // ... остальные действия
}
```


## 🔧 Добавление нового действия

### Шаги добавления:

1. **Выбрать свободный код** (230-254 для новых действий)
2. **Добавить в ProgAction enum** в `src/core/constants/actions.js`
3. **Определить параметры** (label, value, или ничего)
4. **Добавить иконку** в `getActionShortCode()` в `program-formatter.js`
5. **Добавить в категорию** в UI палитре
6. **Обновить валидацию** если необходимо
7. **Добавить тесты**

### Пример добавления действия:

```javascript
// 1. Добавить в enum
const ProgAction = {
  // ... существующие действия
  TeleportToXY: 230,  // Новое действие
}

// 2. Добавить иконку
function getActionShortCode(action) {
  switch(action) {
    case ProgAction.TeleportToXY: return "📍";
    // ... остальные
  }
}

// 3. Добавить логику размещения в ProgrammatorUI
if (actionCode === ProgAction.TeleportToXY) {
  // Логика для действий с двумя параметрами
  const coords = await this.promptForCoordinates("Enter X,Y coordinates:");
  instruction.value = coords; // {x: 10, y: 20}
}
```

## 📋 Спецификация параметров

### Типы параметров:
- **label**: string - текстовая метка для переходов
- **value**: number - числовое значение
- **coords**: {x: number, y: number} - координаты
- **range**: number - радиус/диапазон
- **condition**: boolean - условие

### Валидация параметров:
- **label**: не пустой, без пробелов, уникальный
- **value**: целое число 0-9999
- **coords**: x,y в пределах карты (0-255)
- **range**: положительное число 1-100
