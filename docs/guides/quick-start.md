# 🚀 Быстрый старт по документации

## 🎯 Для чего эта документация?

Эта система документации позволяет вам **описывать требования** в промптах, а AI реализует функции на основе спецификаций. Нет нужды в детальном кодинге - просто опишите, что нужно сделать!

## 📋 Как добавить новую функцию

### Шаг 1: Напишите промпт
```
Добавь функцию [НАЗВАНИЕ] которая делает [ОПИСАНИЕ]

Требования:
- [Что должно работать]
- [Как интегрироваться]
- [Особые условия]

Смотри спецификации в docs/[раздел]/[файл].md
```

### Шаг 2: AI реализует на основе документации
- Анализирует существующий код
- Следует архитектурным принципам
- Добавляет необходимые тесты
- Обновляет документацию

### Шаг 3: Тестирование и деплой
- Функция готова к использованию
- Все интеграции работают
- Код соответствует стандартам

## 🎨 Примеры промптов

### Пример 1: Новое действие бота
```
Добавь действие "Телепортация" для бота.

Требования:
- Принимает координаты X,Y
- Проверяет границы карты
- Показывает диалог ввода координат

Смотри docs/specs/ProgAction-enum.md
```

### Пример 2: UI компонент
```
Добавь панель шаблонов программ.

Требования:
- Категории: Mining, Building, Combat
- Drag & drop в сетку
- Сохранение пользовательских шаблонов

Смотри docs/architecture/components.md
```

### Пример 3: Новый формат экспорта
```
Добавь экспорт в JSON формат.

Требования:
- Человеко-читаемая структура
- Включает метаданные программы
- Поддержка импорта обратно

Смотри docs/features/export-import.md
```

## 🎯 Ключевые принципы

### 📏 Следование спецификациям
- Все действия соответствуют ProgAction enum
- Форматы программ стандартизированы
- UI компоненты унифицированы

### 🧱 Модульная архитектура
- Core: бизнес-логика
- UI: пользовательский интерфейс
- Services: внешние сервисы
- Utils: вспомогательные функции

### ✅ Качество кода
- TypeScript-подобные JSDoc
- Обработка ошибок
- Производительность
- Тестируемость

## 🔧 Типичные задачи

### Добавление действия бота
1. Выбрать код в ProgAction enum
2. Добавить в actions.js
3. Добавить иконку в formatter
4. Добавить в UI палитру
5. Обновить валидацию

### Добавление UI компонента
1. Создать класс компонента
2. Добавить в components/index.js
3. Интегрировать в ProgrammatorUI
4. Добавить стили
5. Обновить документацию

### Добавление формата экспорта
1. Добавить в ProgramFormatVersion
2. Реализовать encode/decode
3. Добавить в UI
4. Обновить валидацию

## 🚨 Когда уточнять требования

- Неясно, как функция должна работать
- Конфликт с существующими функциями
- Сложная интеграция
- Performance требования
- Безопасность/валидация

## 📊 Проверка готовности

После реализации функции проверьте:
- ✅ Работает как описано
- ✅ Нет багов в существующих функциях
- ✅ Код соответствует стилю
- ✅ Документация обновлена
- ✅ Тесты написаны
