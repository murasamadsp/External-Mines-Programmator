# 🚀 Руководство по добавлению новых функций

Это руководство объясняет, как добавлять новые функции в External Mines Programmator на основе промптов пользователя.

## 📋 Шаблон промпта для новой функции

```

### Название функции
[Краткое название функции]

### Тип функции
[UI/CORE/SERVICE/UTIL]

### Описание
[Подробное описание того, что должна делать функция]

### Требования
- [Требование 1]
- [Требование 2]
- [Требование 3]

### Интеграция
- [С какими компонентами должна взаимодействовать]
- [Какие API использовать]
- [UI/UX требования]

### Ссылки на спецификации
- docs/architecture/[file].md
- docs/api/[file].md
- docs/features/[file].md
```

## 🎨 Типы функций

### 🔧 CORE (Бизнес-логика)
**Примеры**: Новые действия бота, алгоритмы валидации, модели данных

**Файлы для изменения**:
- `src/core/models/` - новые модели
- `src/core/constants/` - новые константы
- `src/core/services/` - новые сервисы

### 🎨 UI (Пользовательский интерфейс)
**Примеры**: Новые компоненты, улучшения UX, визуальные эффекты

**Файлы для изменения**:
- `src/components/` - новые компоненты
- `src/assets/styles/` - стили
- `src/components/editor/programmator-ui.js` - основной UI

### ⚙️ SERVICE (Сервисы)
**Примеры**: Новая компрессия, API интеграция, хранение данных

**Файлы для изменения**:
- `src/core/services/` - новые сервисы
- `src/utils/helpers/` - вспомогательные функции

### 🔨 UTIL (Утилиты)
**Примеры**: Новые форматтеры, валидаторы, хелперы

**Файлы для изменения**:
- `src/utils/formatters/` - форматтеры
- `src/utils/validators/` - валидаторы
- `src/utils/helpers/` - хелперы

## 📝 Примеры промптов

### Пример 1: Добавление нового действия бота

```
## 🎯 Запрос на новую функцию

### Название функции
Добавить действие "Teleport" (телепортация)

### Тип функции
CORE + UI

### Описание
Добавить новое действие бота, которое позволяет телепортироваться на указанные координаты.

### Требования
- Действие принимает параметры X, Y (координаты)
- Валидация: координаты должны быть в пределах карты
- UI: Показывать диалог для ввода координат

### Интеграция
- Добавить в ProgAction enum
- Добавить в палитру действий (категория Movement)
- Добавить валидацию в program-validator.js
- Добавить отображение в program-formatter.js

### Ссылки на спецификации
- docs/specs/ProgAction-enum.md
- docs/features/programmator-core.md
- docs/api/core-api.md
```

- Определить тип функции
- Выявить зависимости от существующих компонентов

### Шаг 2: Планирование изменений
- Создать список файлов для изменения

## 🚨 Распространенные проблемы

### Проблема: Функция ломает существующий код
**Решение**: Тщательное тестирование, использование feature flags

### Проблема: Сложная интеграция с существующими компонентами
**Решение**: Начать с isolated компонента, затем интегрировать постепенно

### Проблема: Performance degradation
**Решение**: Профилирование, оптимизации, lazy loading

### Проблема: Недостаточно детальный промпт
**Решение**: Запросить уточнения, привести примеры использования
