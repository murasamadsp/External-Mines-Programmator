# External Mines Programmator (EMP) 🚀

## ✨ Особливості

- **🎯 Візуальне програмування** - створюйте програми через  
  інтуїтивний drag-and-drop інтерфейс
- **🎨 Сучасний дизайн** - glassmorphism ефекти, плавні анімації  
  та адаптивний темний дизайн
- **⚡ Висока продуктивність** - оптимізований збірник з lazy loading та code splitting
- **🔒 Desktop-only** - оптимізовано для стаціонарних пристроїв з блокуванням мобільних
- **🗜️ LZMA стиснення** - ефективне стиснення програм з використанням LZMA алгоритму
- **🎪 Інтерактивні ефекти** - hover ефекти, анімації  
  та візуальні зворотні зв'язки
- **🎯 Декодер програм** - вбудований інструмент для перетворення  
  текстових програм Mines у цифровий формат
- **📊 Аналізатор програм** - інструмент для аналізу та оптимізації програм з рекомендаціями

- npm або yarn

```bash

# Встановлення залежностей

# Запуск в режимі розробки

# Збірка для продакшну

# Попередній перегляд збірки
```

## 🎯 Декодер програм

EMP включає вбудований декодер програм, який дозволяє перетворювати  
текстові оператори Mines у цифровий формат програм.

### Підтримувані оператори

```text
Рух: W A S D (вверх, вліво, вниз, вправо)
Дії: Z0 (копати), w a s d (поворот)
Умови: c0 (не порожньо), c1 (порожньо)
Логіка: M0 (OR), M1 (AND)
І багато інших...
```

### Як декодувати програму

1. Відкрийте секцію "Program Decoder" на панелі керування
2. Натисніть "Відкрити декодер"
3. Введіть оператори через пробіл (наприклад: `W A S D Z0`)
4. Натисніть "Декодувати"
5. Отримайте цифровий код для використання в програмах

## 📊 Аналізатор програм

EMP включає потужний аналізатор програм, який надає детальну  
статистику та рекомендації з оптимізації.

### Що аналізується

- **Кількість інструкцій** - загальна та по категоріях
- **Різноманітність дій** - унікальні операції
- **Використання ресурсів** - умови, логіка, мітки
- **Ефективність** - рекомендації з покращення

### Категорії аналізу

```text
📈 Статистика:
• Загальна кількість інструкцій
• Унікальних дій та їх розподіл
• Рухових операцій
• Логічних операцій
• Умовних перевірок
• Міткованих інструкцій

💡 Рекомендації:
• Оптимізація великих програм
• Покращення логіки прийняття рішень
• Додавання міток для кращого контролю
• Використання RepeatLastAction
```

### Як аналізувати програму

1. Відкрийте секцію "Program Analyzer" на панелі керування
2. Натисніть "Відкрити аналізатор"
3. Перегляньте статистику вашої програми
4. Ознайомтеся з рекомендаціями з оптимізації
5. Застосуйте поради для покращення ефективності
