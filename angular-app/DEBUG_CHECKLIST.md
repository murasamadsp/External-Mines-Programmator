# Debug Checklist

Будь ласка, відкрийте http://localhost:4200/ та перевірте:

## 1. Візуальне відображення

- [ ] Сторінка завантажується
- [ ] Видно заголовок "External Mines Programmator"
- [ ] Ліва панель (Action Palette) видима
- [ ] Центральна сітка (16x12) видима
- [ ] Права панель (Snippets) видима
- [ ] Кнопки Controls видимі

## 2. Консольні помилки

Відкрийте DevTools (F12) → Console та повідомте всі червоні помилки:

```
[Скопіюйте сюди помилки]
```

## 3. Функціональність

- [ ] Клік на action в палітрі виділяє його?
- [ ] Drag & drop з палітри на сітку працює?
- [ ] Кнопка Import працює?
- [ ] Кнопка Export працює?
- [ ] Page навігація працює?
- [ ] Tools dropdown відкривається?
- [ ] Decoder modal відкривається?
- [ ] Snippets cards кліка
